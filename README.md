# MineStars Server Engine
A lightweight and powerful server engine, which allows the usage of external mods **addons** for complex modifications into the engine.

## This engine gives this features:
- Multi map: Multiple maps at once on the server.
- Multi server: The server can create subservers. _main->slave1;slave2_
- Refactored code: Easier reading code from **core/** and many more folders for pure C coding.
- Add-ons: A next version of "mods", allows special manipulation.

### Warnings
- This modding are much insecure by this time.
- Multi server protocols may collapse if used incorrectly.
