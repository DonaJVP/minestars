# MineStars Server Engine
A lightweight and powerful server engine, which allows the usage of external mods **addons** for complex modifications into the engine.

## This engine gives this features:
- Multi map: Multiple maps at once on the server, allows more "dimensions".
- Multi server: The server can create subservers to join. _main->slave1;slave2_
- Refactored code: Easier reading code from **core/** and many more folders for pure C coding.
- Add-ons: Lua mods have been erased completely from the engine to allow Add-ons run correctly. _There will be a LuaTest addon soon.._

### Warnings
- This engine modding are much insecure by this time, as this was a new idea to include other games be compatible with this, as Minecraft.
- Multi server protocols may collapse a time if used incorrectly.
